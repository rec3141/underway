# Collaboration preferences

- Keep the user in the loop with concise progress updates during ongoing work; never leave them waiting more than 60 seconds without an update.
- Use short, bounded tool calls and narrowly scoped searches. A simple file read should not be delayed behind a broad filesystem search; surface delays promptly.
- The user authorizes agents for small, independent tasks when delegation improves turnaround. Keep the main conversation responsive while they work.
- Use Atlas for the lead agent and names such as Piper, Finch, and Nova for other agents in user-facing updates. Do not use internal task paths or the earlier “baby” terminology.
