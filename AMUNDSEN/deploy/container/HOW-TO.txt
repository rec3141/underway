UNDERWAY DASHBOARD - HOW TO RUN IT
==================================

What it is: the web page that shows the ship's underway data, CTD casts, map,
cameras, schedule, wiki and games. One computer on the ship runs it; everyone
else just opens it in a browser.

1. ONCE: INSTALL DOCKER on the computer that will run it
   - Linux:   ask for "docker" and "docker compose" to be installed
              (Ubuntu: sudo apt install docker.io docker-compose-v2)
   - Windows or Mac: install "Docker Desktop" from docker.com and start it.
   The computer must be on the ship's wired network (10.0.0.x).

2. START IT
   - Linux/Mac: open this folder and run   ./start.sh
   - Windows:   double-click   start.bat
   The first start takes a few minutes. It prints the web address and the
   PASSWORD FOR THE SETTINGS PAGE (also saved in ADMIN-PASSWORD.txt).
   After that it starts by itself whenever the computer restarts.

3. FILL IN THE SETTINGS  (open  http://<address>/settings  and log in)
   - Ship shares: the user name and password for the ship's file server
     (the same ones used to open \\10.0.0.10\Data). Without them the page
     has no data.
   - Cameras: the leg name and the leg's Pictures/Timelapse folder.
   - Optional: Telegram bot, email for alerts, satellite, Google Calendar.
     Anything left empty is simply switched off.
   Press Save. It takes about a minute for the page to show new data.

4. TELL PEOPLE THE ADDRESS
   http://<this computer's address>/    for example http://10.0.0.58/
   Tip (Linux): name the computer "underway" and it also answers at
   http://underway.local/ on most laptops and iPhones (not Android).

EVERYDAY
   Stop:            ./stop.sh    or  stop.bat      (nothing is lost)
   Start again:     ./start.sh   or  start.bat
   Is it working?   ./status.sh, or open http://<address>/status.html

IF SOMETHING IS WRONG
   - Page does not open: is the computer on and Docker running? Run start again.
     Use the numeric address (http://10.0.0.x/), and http:// not https://.
   - Page opens but data is old: check the Ship shares settings; the file
     server may have restarted (it reconnects by itself within a minute).
   - Still stuck: restart the computer, then run start again.
   - Everything the dashboard keeps is in the "data" folder beside this file.
     Back that folder up at the end of the leg; do not delete it.

NEW LEG
   On the settings page change the camera leg name and timelapse folder.
   Nothing else is needed: new leg folders on the file server are found
   automatically.
